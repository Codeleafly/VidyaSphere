VidyaSphere Kya Hai?
School ka Next-Generation Digital Ecosystem

VidyaSphere aapke school ka digital hub hai jahan par aapko:

  • School ke sabhi urgent Announcements & Notice sabse pehle milte hain.
  • Maharashtra State Board (SSC/HSC) aur CBSE ke sabhi subjects ke Study Notes & PDFs milte hain.
  • Koi bhi question poochne aur classmates se solution paane ke liye Academic Q&A Forum milta hai.
  • School aur Class activities par apna vote dene ke liye Live Polls milte hain.
  • Sabhi Class 1 se Class 12 tak ke students ke liye secure Realtime Class Chat milta hai.
💡 Zero App Download Needed: Is website ko chalane ke liye Play Store se koi bhari app download karne ki zaroorat nahi hai. Yeh browser mein hi instant khulti hai aur phone ki memory bilkul nahi leti!
1
Admission & Account Registration
Pehli baar aane par apna khata (account) kaise banayein
Step 1.1: Registration Page Kholein

Website ke homepage par jayein aur "Apply for Admission" par click karein ya direct is link par jayein:

/auth/register

Step 1.2: Apni Real Details Bharein
  • Full Name: Apna poora real school name likhein (Jaise: Aarav Rajesh Sharma).
  • Standard (Class): Class 1 se lekar Class 12 mein se apni class select karein.
  • Division: Apni section division chunein (A, B, C, D).
  • Roll Number: Apna school roll number enter karein (e.g. 15).
  • Username: Ek simple username banayein bina space ke (e.g. aarav_10a).
  • Password: Ek strong password banayein jise aap yaad rakh sakein.
Step 1.3: Registration Tracking Token Ko Save Karein (Sabse Zaroori!)

Form submit karne ke baad screen par ek popup aayega jismein aapko ek unique token milega:

Registration Success Screen
Registration Successful!
Your Application Token:
VSR-9A4B2C81
[ 📋 Copy Token Button ]
⚠️ Dhyan Dein: Is token ko copy karke kahin likh lein ya screenshot le lein. Kyunki school ki security ke liye fake accounts ko rokne ke liye, Lead Admin aapke form ko approve karenge. Approval status check karne ke liye yeh token zaroori hai!
2
Application Status & Account Activation
Admin approval check karna aur 6-digit code se activate karna
Step 2.1: Status Tracker Page Par Jayein

Website par "Check Application Status" par click karein (/auth/status).

Step 2.2: Apna Token Dalein

Apna VSR-XXXXXXXX token dalein aur "Track Application" par click karein.

Screen par 3 tarah ke status dikh sakte hain:

  • 🟡 Pending Review: Lead Admin abhi aapke form ko verify kar rahe hain. Thoda intezar karein.
  • 🟢 Approved (Activation Code Ready): Admin ne aapko approve kar diya hai aur ek 6-digit Secret Code (jaise A7B9X2) issue ho chuka hai!
  • 🔵 Already Active: Aapka account pehle hi activate ho chuka hai, aap direct login kar sakte hain.
Step 2.3: 1-Click Account Activate Karein

Jaise hi aapka status Approved hota hai, screen par "Activate Account Now" ka button dikhega. Us par click karte hi aapka account active ho jayega aur login screen par bhej diya jayega!

3
Daily Sign In (Login Kaise Karein)
Rozana apne account mein enter hone ka tarika
Login Credentials Enter Karein
  1. /auth/login page par jayein.
  2. Apna Username dalein (Jo aapne registration ke samay banaya tha).
  3. Apna Password dalein.
  4. "Sign In" button par click karein.
🔒 256-Bit Cryptographic Security: VidyaSphere mein aapka password encrypted rehta hai aur browser mein auto-login ke liye secure random session token use hota hai. Koi doosra student aapka password chura nahi sakta!
4
Digital Notice Board (School Announcements)
Holidays, timetable aur exam notices dekhna

Login hone ke baad sabse pehla page aapka Dashboard hota hai jahan par School Notice Board dikhta hai:

  • 🔴 Urgent Badges: Achanak hone wali chutti ya zaroori alert.
  • 🟣 Exam Badges: Datesheet, syllabus aur exam hall guidelines.
  • 🟢 Holiday Badges: Festival ya vacation holidays ki jaankari.
  • 🔵 General: Sports day, science exhibition aur annual functions.

Aap upar diye gaye filter se sirf Apni Class ke notices ya poore School-wide notices dekh sakte hain.

5
Study Notes & Material Library
Chapters ke notes padhna aur download karna
Notes Kaise Dhoondhein Aur Download Karein:
  1. Neeche bottom menu mein "Notes" icon par tap karein.
  2. Apni Class select karein (Class 1 to 12).
  3. Apna Subject chunein (CBSE & Maharashtra Board subjects jaise Mathematics, Science, Marathi, History, Geography, Physics, Chemistry, Economics etc.).
  4. Chapter ka naam search bar mein type karein.
  5. Note card par diye gaye "Download Note" button par tap karein. Document turant open ya download ho jayega!
Apne Notes Upload Kaise Karein (Help Your Classmates):

Agar aapke paas kisi chapter ki acchi summary ya hand-written notes hain, toh aap "+ Upload Note" button par click karke title, subject aur chapter likh kar upload kar sakte hain.

6
Academic Q&A Discussion Forum
Doubt poochna aur doosron ke sawalon ke jawab dena

Padhai karte waqt koi question samajh nahi aa raha? Q&A forum ka use karein:

  • Ask a Question: "Ask Question" par tap karein, subject chunein aur apna doubt clearly likhein.
  • Answer Others: Agar aapko kisi classmate ke sawal ka sahi jawab pata hai, toh question card khol kar apna step-by-step solution likhein.
  • ✅ Accepted Solution: Jis student ne sawal poocha tha, agar usko aapka jawab sabse best lage toh woh green checkmark se "Accept Answer" mark kar sakta hai!
7
School Polls & Elections
House captain election aur class surveys mein vote karna

Bottom navigation se "Polls" section mein jayein:

  • Har active poll card mein sawal aur options dikhenge.
  • Apne pasand ke option ke radio circle par tap karein aur "Submit Vote" dabayein.
  • Strict 1 Student = 1 Vote: System duplicate voting allow nahi karta. Vote submit hote hi aapko live percentage aur vote counts dikhenge!
8
Realtime Class Chat
Apni class ke doston ke saath study discussion

Bottom menu se "Chat" section kholein:

  • Yeh WhatsApp ki tarah instant messaging hai, jahan message bhejte hi sabhi online classmates ko live dikhta hai.
  • Code of Conduct: Chat mein sirf padhai, homework aur school projects se judi baatein karein. Abusive ya spam messages bhejne par Lead Admin account ko suspend kar sakte hain.

Frequently Asked Questions (Troubleshooting)
Kahin par phas gaye toh yahan dekhein
Page kholte waqt "This site can't be reached" ya loading issue aaye toh kya karein?

India mein Jio/Airtel SIM users ke liye Chrome mein Secure DNS on karna padta hai: Chrome Settings > Privacy & security > Use secure DNS > Choose "Cloudflare (1.1.1.1)" ya "Google Public DNS" select karein. Iske baad page palkein jhapakte hi khul jayega!

Agar main apna Registration Token (VSR-...) bhool gaya toh?

Apne class teacher ya school ke Platform Creator & Lead Admin se sampark karein. Admin control panel se aapke Roll Number aur Name se aapka account manually find aur activate kar sakte hain.

Kya main apna Password kisi friend ke saath share kar sakta hoon?

Bilkul nahi! Aapke account se jo bhi vote diya jayega ya doubt poocha jayega, woh aapke naam aur roll number ke sath link hota hai. Apna password kisi ko na dein.

Kya main apne phone ke mobile data (1GB/day) par isko chala sakta hoon?

Haan! VidyaSphere ko specially Ultra Light-weight Architecture par banaya gaya hai. Yeh bohot kam internet data use karta hai aur 4G/5G par super fast chalta hai.
